# 參考文件

使用者提供的公開政府文件，作為地圖圖例、分類說明與查詢結果的依據。

- `國土利用調查_土地使用分類系統表.pdf`：國土利用現況調查土地使用分類（9 大類／41 類／103 類，含代碼與說明）
- `都市計畫_統一圖例.pdf`：都市計畫擬定計畫圖例（各使用分區與公共設施用地的統一圖例與 RGB）
- `非都市土地_使用分區與使用地編定原則表.pdf`：製定非都市土地使用分區圖及編定各種使用地作業須知之編定原則表（ˇ 可編定、△ 依條件編定）
- 相關連結（內容未能確認：2026-11-11 查證時 pip.moi.gov.tw 回應「Request Rejected」、glrs.moi.gov.tw/LawContent.aspx?id=FL003673 連線被中斷，搜尋引擎也查不到內容）：https://pip.moi.gov.tw/Publicize/Info/Z2060
- `國土測繪圖資服務雲_非都市土地使用地類別圖例.png`：使用者從國土測繪圖資服務雲（maps.nlsc.gov.tw）截取的「非都市土地使用地類別」圖例。說明文字：依地籍圖原始儲存資料，依內政部頒布非都市土地使用地類別圖例相關規定自動產製，供套疊運用參考。

  從圖例量到的底色（RGB）：農牧 252,242,80；丁建 119,47,48；甲／乙／丙建 211,45,37（三者完全相同）；暫未編定 151,29,126；海域 216,216,216＋灰斜線；養殖 74,164,228；林業 128,179,69；窯業 119,47,48＋斜線；鹽業 50,115,188；特定目的事業 211,45,37＋斜線；殯葬 181,181,182＋斜線；國土保安 128,179,69＋深綠斜線；生態保護 白底＋淡綠斜線；古蹟保存 白底＋灰斜線；遊憩 215,93,150；水利 50,115,188＋淺藍斜線；交通 119,47,48＋淺粉斜線；礦業 119,47,48＋紫斜線。
- `國土利用現況調查_109年版分類色碼表.webp`：使用者提供的「109 年版國土利用現況調查成果分類色碼表」截圖。
- `國土利用現況調查_109年版分類色碼表.csv`：依上圖逐格轉錄的 150 列（第一級 2 碼、第二級 4 碼、第三級 6 碼）。為人工轉錄，使用前請再抽查。第三級 93 類的顏色互不重複，可用圖磚顏色反查類別。
- `國土利用現況調查辦法_附表一_土地利用分級分類系統表_陸域.pdf`：《國土利用現況調查辦法》附表一（內政部 108 年 3 月 28 日發布，全國法規資料庫 PCODE=D0070276 下載）。這是 108 年版分類系統，代碼與 109 年版色碼表、LUIMAP 圖磚一致，網站的分類說明依此表。
  注意：上面的 `國土利用調查_土地使用分類系統表.pdf` 是較舊的 104 年版（9 大類／41 類／103 類），代碼與現行圖磚不同，網站沒有採用。
- 使用地類別圖磚實測（2026-11-11）：圖磚的顏色和截圖量到的 RGB 略有差異，網站採圖磚實際色：農牧 255,241,0；林業 112,181,44（＋深綠 0,105,62 斜線＝國土保安）；丁建 129,41,45（＋深綠斜線＝窯業、＋白斜線＝交通、＋紫 117,124,187 斜線＝礦業）；甲／乙／丙建 230,0,18（＋深綠斜線＝特定目的事業）；鹽業 0,117,194（＋白斜線＝水利）；養殖 0,167,234；遊憩 232,82,152；暫未編定 165,0,130；殯葬 181,181,182＋黑 35,24,21 斜線。生態保護、古蹟保存、海域用地在實測樣本中沒有出現，依圖例推定（未能確認）。
