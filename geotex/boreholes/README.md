# 鑽孔柱狀圖

地熱地圖「工程井」組裡的「鑽孔柱狀圖」圖層。資料來自經濟部地質調查及礦業管理中心的[工程地質探勘資料庫](https://geotech.gsmma.gov.tw/imoeagis/Home/Map)。

- `geotex/bh_logs.js`：一孔一行的清單（坐標、深度、工程名稱、日期、鑽探公司、頁數等）。
- `geotex/boreholes/<id>_p<頁>.png`：每一頁柱狀圖。`<id>` 是「計畫編號_孔號」，計畫編號裡的括號會拿掉，例如 `01053383-A0684_DB-24-1`。

## 新增鑽孔（建議做法）

從資料庫下載的柱狀圖，檔名長這樣：`____40401902-1120403_10YL-DS-S070_001.emf`。
中間的 `40401902-1120403_10YL-DS-S070` 就是要給工具的參數（計畫編號_孔號）。

在 repo 根目錄執行（電腦要能連到 geotech.gsmma.gov.tw）：

```
python3 tools/add_borehole.py 40401902-1120403_10YL-DS-S070 2841255011038_DH-9
```

一次可以給好幾孔。工具會自動：

1. 到資料庫的鑽孔圖層找出坐標（WGS84）與深度；
2. 下載**全部頁數**的柱狀圖到這個資料夾；
3. 讀基本資料（工程名稱、地點、高程、原始坐標、日期、鑽探公司）；
4. 新增或更新 `geotex/bh_logs.js` 裡那一筆。

不用自己準備圖片，也不用管頁數。同一孔號在不同計畫可能重複（例如 PA-1），所以一定要連計畫編號一起給。

## 也可以直接把檔案丟給 Claude

把下載的 `.emf` 檔（其實是 PNG 圖）傳上來就好，Claude 會從檔名認出計畫編號與孔號，再用上面的工具抓完整資料。

## 已知狀況

- 少數孔在資料庫查「基本資料」會出錯（例如 BP-22-1），工具仍會加入坐標與柱狀圖，並在備註寫明。
- 原始坐標是 TWD67 的孔，地圖用的是資料庫圖層換算好的 WGS84。

## 資料格式（geotex/bh_logs.js 一行一孔）

必要欄位：

| 欄位 | 說明 |
|---|---|
| `id` | 唯一代號，建議「計畫編號_孔號」（去掉括號）；也是圖片檔名前綴 |
| `hole` | 孔號 |
| `proj` | 計畫編號 |
| `lat`, `lng` | WGS84 經緯度（小數 7 位） |

選填欄位（沒有就省略或給空字串／null）：

| 欄位 | 說明 |
|---|---|
| `name` | 工程名稱 |
| `loc` | 鑽孔地點 |
| `elev` | 孔口高程（m） |
| `depth` | 鑽孔深度（m） |
| `crs`, `x`, `y` | 原始坐標系統（`TW97`／`TW67`）與 X、Y |
| `start`, `end` | 鑽探起訖日期，民國「年-月-日」，例如 `112-04-19` |
| `company` | 鑽探公司 |
| `gwl`, `gwlDate` | 地下水位（地表下 m）與量測日期 |
| `layers` | 分層：`[{"top":0,"bot":2.1,"desc":"卵礫石夾灰色中細砂","uscs":"GP"}, …]`（`uscs` 可省略） |
| `spt` | 標準貫入試驗：`[{"depth":1.5,"n":"29"}, …]`（`n` 可以是 `"50/12"` 這種文字） |
| `pages` | 柱狀圖頁數；有圖片時才填，圖片放 `geotex/boreholes/<id>_p<頁>.png` |
| `source` | 資料來源文字；沒填時顯示「地調中心工程地質探勘資料庫」 |
| `coordNote` | 坐標說明，例如「TWD67 以 pyproj（EPSG:3828→4326）換算，誤差約數公尺」；沒填時依 `source` 自動寫 |
| `note` | 備註 |

彈窗會依有填的欄位自動顯示；`layers`、`spt` 有資料時會在基本資料下方顯示分層表與 N 值。
