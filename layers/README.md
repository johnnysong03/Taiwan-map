# 程式拆分（漸進式）

`app.js` 太大（約 3,000 行），而且有多個工作階段同時在改，所以採「漸進式拆分」：

- **新功能**一律寫成獨立檔案，不要再加進 `app.js`。
- **舊圖層**等沒有人在改的時候，一次搬一塊出來，每搬一塊就在桌機與手機（iPhone 13）測過再推。

## 載入順序（taiwan-geothermal.html）

1. 資料檔（`geotex/*.js` 的目錄與 meta）
2. `app.js`：地圖、底圖、大部分圖層
3. `layers/*.js`：從 app.js 拆出來的圖層
4. `ui.js`：介面整理（可收合區塊、搜尋圖層、已開啟標籤、手機分頁、網址狀態、找地點、進度條、浮動圖例）

`ui.js` 一定要最後載入：它會掃描所有圖層勾選框（要有 `id`），網址還原也靠這些 `id`。

## 寫法約定

- 檔案用 `(()=>{ ... })();` 包起來，開頭先檢查 `APP`，不是對應的地圖就 `return`。
- 可以用 `app.js` 的全域：`map`、`L2`、`T`、`EN`、`APP`、`MOBILE`、`sheet`。
  `app.js` 裡 `if(APP==="geo"){...}` 區塊內的東西（例如 `hesc`）外面拿不到，需要的話自己定義或掛到 `window._geo`。
- 勾選框請給固定的 `id`，`ui.js` 才找得到（搜尋圖層、已開啟標籤、分享連結）。
